# Seguridad

Square procesa archivos locales con bibliotecas y ejecutables nativos. Mantené actualizados los motores y abrí archivos de fuentes confiables.

Para informar un problema sensible, usá [Private vulnerability reporting](https://github.com/xXKuroiKenshiXx/Square/security/advisories/new) si GitHub lo muestra disponible. Si no está habilitado, abrí un issue que solicite un canal privado **sin incluir el exploit, credenciales ni archivos privados**.

La versión 0.2 es preliminar. No existe todavía un proceso de actualización automática ni una garantía de soporte para versiones antiguas. Los instaladores no están firmados.

No envíes documentos personales como muestra de un error. Prepará un archivo mínimo sin información sensible y eliminá nombres, rutas y contenido privado de capturas y registros.
